# i:Store — интернет-магазин техники Apple

Полноценный интернет-магазин, написанный с нуля:

- **Frontend** — витрина в минималистичной стилистике (белый фон, красный акцент,
  по мотивам дизайна re-store.ru): главная, каталог с фильтрами, карточка товара,
  корзина, оформление заказа.
- **Backend** — REST API на чистом Node.js **без внешних зависимостей**
  (не нужен `npm install`), данные хранятся в JSON-файлах.
- **Админка** — панель администратора в стиле OpenCart: дашборд с плитками
  статистики, управление товарами, заказами и категориями.

## Запуск

```bash
cd apple-store
node server.js
```

| Адрес | Что это |
|---|---|
| http://localhost:3000 | Витрина магазина |
| http://localhost:3000/admin | Админ-панель |

**Доступ в админку:** логин `admin`, пароль `admin`
(сменить можно в `data/settings.json`: поля `adminUser` и `adminPasswordHash` — sha256-хэш пароля).

## Структура проекта

│   ├── product.html     # Карточка товара: цвета, характеристики, похожие товары
│   ├── cart.html        # Корзина (хранится в localStorage)
│   ├── checkout.html    # Оформление заказа
│   ├── css/style.css
│   ├── js/              # app.js (общее), catalog.js
│   └── img/             # Собственные SVG-иллюстрации товаров

## REST API

### Публичные

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/categories` | Список категорий |
| GET | `/api/products` | Каталог: `?category=`, `?search=`, `?minPrice=`, `?maxPrice=`, `?sort=price_asc\|price_desc\|new\|name`, `?page=`, `?limit=` |
| GET | `/api/products/:id` | Карточка товара |
| POST | `/api/orders` | Оформить заказ `{ customer, items: [{id, qty}] }` — цены берутся из каталога на сервере |

### Админка (заголовок `Authorization: Bearer <token>`)

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/admin/login` | `{username, password}` → `{token}` |
| GET | `/api/admin/stats` | Статистика для дашборда |
| GET / POST | `/api/admin/products` | Список / создание товара |
| PUT / DELETE | `/api/admin/products/:id` | Обновление / удаление |
| GET | `/api/admin/orders` | Все заказы |
| PUT | `/api/admin/orders/:id` | Смена статуса (`new → processing → shipped → completed / cancelled`) |
| POST / DELETE | `/api/admin/categories[/:slug]` | Управление категориями |

## Возможности

**Витрина:** поиск по каталогу, фильтры, сортировка, бейджи («Хит», «Новинка»,
«Скидка»), старая/новая цена, выбор цвета, корзина с изменением количества,
расчёт доставки, оформление заказа с выбором доставки и оплаты, адаптивная вёрстка.

**Админка:** авторизация по токену (sha256-хэш пароля, сессия 8 часов), дашборд
(заказы, продажи, товары, покупатели, последние заказы), добавление и
редактирование товаров через модальное окно (включая характеристики и бейджи),
включение/отключение товаров, смена статусов заказов, просмотр состава заказа,
управление категориями.

> Дизайн витрины выполнен «по мотивам» re-store.ru (структура и цветовая схема),
> весь код, тексты и SVG-графика — оригинальные. Учебный проект; Apple, iPhone,
> iPad и др. — товарные знаки Apple Inc.
