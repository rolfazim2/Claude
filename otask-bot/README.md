# otask-bot

Telegram-бот для [otask.ru](https://otask.ru) (таск-трекер O!task). Работает поверх
официального API [`api.otask.ru`](https://api.otask.ru/docs) (REST, Bearer-авторизация).

## Возможности

| # | Что | Команда |
|---|-----|---------|
| 1 | Назначенные задачи | `/tasks` |
| 2 | Описание, сроки, приоритеты | `/task <id>` (карточка), они же видны в списках |
| 3 | Просрочки | `/overdue` (а также пометка ⚠️ в любом списке) |
| 4 | Напоминания о скором дедлайне | автоматически + `/reminders on\|off`, предпросмотр `/soon` |
| 5 | Постановка задачи | `/new` (мастер) или однострочный синтаксис |

### Команды

```
/start              — приветствие, подписка на напоминания
/help               — список команд
/tasks              — назначенные задачи (без завершённых)
/overdue            — только просроченные
/soon               — у которых дедлайн в ближайшие REMINDER_LEAD_HOURS часов
/task <id>          — полная карточка задачи
/new                — поставить задачу пошагово (заголовок → описание → срок → приоритет)
/new Заголовок | описание | 2026-06-10 18:00 | high   — создать одной строкой
/reminders on|off   — включить/выключить напоминания о дедлайнах
/cancel             — отменить мастер создания задачи
```

Форматы срока: `2026-06-10 18:00`, `2026-06-10`, `10.06.2026 18:00`.
Приоритеты: `low` / `normal` / `high` / `critical` (понимает и русские слова).

## Режим работы

**Одноаккаунтный**: один общий API-ключ otask (`OTASK_API_KEY`) используется для всех
пользователей бота — все видят один и тот же набор задач команды/аккаунта. Подходит для
одной команды или общего аккаунта otask.

**Запуск**: long-polling (бот сам опрашивает Telegram) + фоновый планировщик APScheduler
для напоминаний. Достаточно одного постоянно работающего процесса, входящий HTTPS не нужен.

## Напоминания

Планировщик опрашивает API каждые `REMINDER_POLL_MINUTES` минут и шлёт всем подписанным
чатам (тем, кто сделал `/start` и не выключил напоминания):

- **⏰ Скоро дедлайн** — когда до срока осталось ≤ `REMINDER_LEAD_HOURS` часов;
- **⚠️ Просрочена** — когда срок прошёл.

Каждое напоминание по задаче отправляется один раз (дедупликация в `data/store.json`).
Если дедлайн перенесли в будущее — напоминание сможет прийти снова.

## Запуск

```bash
cp .env.example .env          # заполните BOT_TOKEN и OTASK_API_KEY
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

### Переменные окружения

| Переменная | Назначение | По умолчанию |
|------------|-----------|--------------|
| `BOT_TOKEN` | токен бота от @BotFather | — (обязательно) |
| `OTASK_API_KEY` | общий API-ключ otask | — (обязательно) |
| `OTASK_API_BASE` | базовый URL API | `https://api.otask.ru` |
| `DATA_DIR` | каталог хранилища | `./data` |
| `REMINDER_LEAD_HOURS` | за сколько часов напоминать | `24` |
| `REMINDER_POLL_MINUTES` | период опроса API | `15` |
| `TIMEZONE` | пояс для отображения дат | `Europe/Moscow` |

## Архитектура

```
main.py               — точка входа: long-polling + планировщик
bot/
  config.py           — чтение и валидация env
  otask_client.py     — клиент API otask (list/get/create) + нормализация ответов
  formatting.py       — карточки/списки, сортировка, метки просрочки, часовой пояс
  handlers.py         — команды (aiogram Router) + FSM-мастер создания задачи
  reminders.py        — прогон напоминаний (вызывается планировщиком)
  store.py            — файловое хранилище (подписчики, дедуп напоминаний)
```

### Подгонка под реальную схему API

Сеть окружения разработки не имеет доступа к `api.otask.ru`, поэтому точные пути и имена
полей нужно сверить с [`api.otask.ru/docs`](https://api.otask.ru/docs). Всё, что зависит
от схемы API, изолировано в **`bot/otask_client.py`**:

- словарь `ENDPOINTS` — пути (`/tasks`, `/tasks/{id}`, POST `/tasks`);
- `list_assigned_tasks()` — query-параметры выборки назначенных задач (`?assigned=me`);
- `_normalize_task()` — маппинг полей ответа (терпим к разным именам: `name`/`title`,
  `due_date`/`deadline`, `priority`/`importance` и т.д.);
- `_serialize_create()` — тело запроса при создании задачи;
- `_build_url()` — шаблон ссылки на карточку в веб-интерфейсе.

Остальной код бота от схемы не зависит — правки нужны только в этом файле.
