# otask-bot

Telegram-бот для [otask.ru](https://otask.ru) (таск-трекер O!task). Работает поверх
официального API [`api.otask.ru`](https://api.otask.ru/docs) (REST, Bearer-авторизация).

## Возможности

| # | Что | Команда |
|---|-----|---------|
| 1 | Назначенные задачи | `/tasks` |
| 2 | Описание, сроки, приоритеты | `/task <id>` (карточка), они же видны в списках |
| 3 | Просрочки | `/overdue` (а также пометка ⚠️ в любом списке) |
| 4 | Напоминания о скором дедлайне | автоматически + `/reminders on\|off`, предпросмотр `/soon` |
| 5 | Постановка задачи | `/new` (мастер) или однострочный синтаксис |

### Команды

```
/start              — приветствие и краткая справка
/help               — список команд
/link <ключ>        — привязать ваш API-ключ otask (проверяется при привязке)
/unlink             — отвязать ключ
/tasks              — назначенные на вас задачи (без завершённых)
/overdue            — только просроченные
/soon               — у которых дедлайн в ближайшие REMINDER_LEAD_HOURS часов
/task <id>          — полная карточка задачи
/new                — поставить задачу пошагово (заголовок → описание → срок → приоритет)
/new Заголовок | описание | 2026-06-10 18:00 | high   — создать одной строкой
/reminders on|off   — включить/выключить напоминания о дедлайнах
/cancel             — отменить мастер создания задачи
```

Поддерживаемые форматы срока: `2026-06-10 18:00`, `2026-06-10`, `10.06.2026 18:00`.
Приоритеты: `low` / `normal` / `high` / `critical` (понимает и русские слова).

## Напоминания

Фоновый планировщик опрашивает API каждые `REMINDER_POLL_MINUTES` минут и присылает:

- **⏰ Скоро дедлайн** — когда до срока осталось ≤ `REMINDER_LEAD_HOURS` часов;
- **⚠️ Просрочена** — когда срок прошёл.

Каждое напоминание по задаче отправляется один раз (дедупликация в `data/store.json`).
Если дедлайн задачи перенесли в будущее, напоминание сможет прийти снова.

## Запуск

```bash
cp .env.example .env      # заполните BOT_TOKEN и при желании OTASK_API_KEY
npm install
npm start                 # tsx src/index.ts (long-polling)
```

`npm run dev` — то же с авто-перезапуском, `npm run typecheck` — проверка типов.

### Переменные окружения

| Переменная | Назначение | По умолчанию |
|------------|-----------|--------------|
| `BOT_TOKEN` | токен бота от @BotFather | — (обязательно) |
| `OTASK_API_BASE` | базовый URL API | `https://api.otask.ru` |
| `OTASK_API_KEY` | общий ключ для всех (одноаккаунтный режим) | пусто |
| `DATA_DIR` | каталог хранилища | `./data` |
| `REMINDER_LEAD_HOURS` | за сколько часов напоминать | `24` |
| `REMINDER_POLL_MINUTES` | период опроса API | `15` |

### Режимы доступа

- **Многопользовательский** (по умолчанию): каждый пользователь привязывает свой ключ
  через `/link`. Ключ хранится локально, сообщение с ключом бот удаляет из чата.
- **Одноаккаунтный**: задайте `OTASK_API_KEY` в `.env` — он используется для всех, кто
  не привязал собственный ключ.

## Архитектура

```
src/
  index.ts          — точка входа: запуск бота + планировщика, graceful shutdown
  config.ts         — чтение и валидация env
  bot.ts            — команды Telegram (grammY) и мастер создания задачи
  reminders.ts      — фоновый планировщик напоминаний
  store.ts          — файловое хранилище (привязки ключей, дедуп напоминаний)
  format.ts         — форматирование карточек/списков, сортировка, метки просрочки
  otask/
    client.ts       — клиент API otask (list/get/create) + нормализация ответов
    types.ts        — внутренние типы задач
```

### Подгонка под реальную схему API

Сеть этого окружения не имеет доступа к `api.otask.ru`, поэтому точные пути и имена
полей нужно сверить с [`api.otask.ru/docs`](https://api.otask.ru/docs). Всё, что зависит
от схемы API, изолировано в **`src/otask/client.ts`**:

- объект `ENDPOINTS` — пути (`/tasks`, `/tasks/{id}`, POST `/tasks`);
- `listAssignedTasks()` — query-параметры выборки назначенных задач (`?assigned=me`);
- `normalizeTask()` — маппинг полей ответа (уже терпим к разным именам: `name`/`title`,
  `due_date`/`deadline`, `priority`/`importance` и т.д.);
- `serializeCreate()` — тело запроса при создании задачи;
- `buildUrl()` — шаблон ссылки на карточку в веб-интерфейсе.

Остальной код бота от схемы не зависит — правки нужны только в этом файле.
