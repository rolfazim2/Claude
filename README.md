# TaskFlow

Корпоративный таск-менеджер: **Telegram-бот + веб-кабинет** (single-tenant, TZ Europe/Moscow).
Дизайн в духе ClickUp/Asana, скорость — как Linear. Основная работа ведётся в Telegram, веб — рабочий кабинет.

> Полный продуктовый и технический дизайн — в [DESIGN.md](./DESIGN.md).

## Структура (монорепо, pnpm)

```
taskflow/
├── apps/
│   ├── web/      # Веб-кабинет: React + Vite + TS + Tailwind (дизайн-система + прототип)
│   ├── api/      # Бэкенд: Fastify (скелет; далее Postgres/Prisma, auth, WS, планировщик)
│   └── bot/      # Telegram-бот: grammY (скелет меню и действий)
└── packages/
    └── shared/   # Общие доменные типы и перечисления (статусы, приоритеты, роли…)
```

## Запуск на сервере (Docker)

```bash
cp .env.example .env                 # при необходимости поменяйте пароли/URL
docker compose up -d --build         # поднимет Postgres + API + Web
docker compose exec api pnpm seed    # (опционально) демо-данные
```

- Веб: `http://SERVER:8080` · API: `http://SERVER:3001`
- Для прод-домена задайте `VITE_API_URL` в `.env` (публичный адрес API).

## Локальная разработка

```bash
pnpm install
# Postgres любой; задайте DATABASE_URL для API
pnpm --filter @taskflow/api exec prisma migrate dev   # миграции
pnpm --filter @taskflow/api seed                       # демо-данные
pnpm dev:api            # API на :3001
pnpm dev:web            # веб на :5173
# pnpm dev:bot          # бот (в самом конце, нужен BOT_TOKEN)
```

## Статус

**Итерация 1 — дизайн и структура** ✅
Монорепо, общие типы, дизайн-система (тёмная + **светлая** тема), все экраны
веб-кабинета (вход, мои задачи, канбан/список с drag&drop, карточка задачи,
функциональная схема, входящие, отчёты), адаптив/мобильная версия.

**Итерация 2 — рабочий бэкенд (Этап A)** ✅
- PostgreSQL + Prisma: полная схема домена, миграции, сид.
- API (Fastify): реальные CRUD, **права/видимость по ролям**, запрет удаления,
  блокировка закрытия без доказательства, комментарии, уведомления, отчёты.
- **Real-time** через WebSocket.
- Веб подключён к API (вход-выбор сотрудника, создание задач, смена статуса,
  доказательства, комментарии) — моки убраны.
- Docker-развёртывание.
