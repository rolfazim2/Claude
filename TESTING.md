# Локальное тестирование TaskFlow (с Telegram-ботом)

Бот **@clatask_bot**. Тестировать нужно на машине с доступом в интернет
(в облачной среде Telegram заблокирован сетевой политикой).

## 1. Подготовка окружения

```bash
git checkout claude/dreamy-babbage-JjQO7
pnpm install
```

Создайте `apps/api/.env`:
```
DATABASE_URL=postgresql://taskflow:taskflow@localhost:5432/taskflow
PORT=3001
BOT_TOKEN=<токен от @BotFather>
BOT_USERNAME=clatask_bot
BOT_SHARED_SECRET=любая-строка
```

Создайте `apps/bot/.env`:
```
BOT_TOKEN=<тот же токен>
API_URL=http://localhost:3001
BOT_SHARED_SECRET=та-же-строка-что-в-api
```

## 2. База данных

Поднимите PostgreSQL (локально или `docker run -e POSTGRES_USER=taskflow -e POSTGRES_PASSWORD=taskflow -e POSTGRES_DB=taskflow -p 5432:5432 -d postgres:16-alpine`), затем:

```bash
pnpm migrate   # применить миграции
pnpm seed      # демо-данные (5 сотрудников, задачи, платежи)
```

## 3. Запуск

Одной командой всё сразу (api + bot + web):
```bash
pnpm dev
```
или по отдельности в трёх терминалах: `pnpm dev:api`, `pnpm dev:bot`, `pnpm dev:web`.

Веб откроется на http://localhost:5173

## 4. Сценарии теста

### Авторизация через Telegram
1. На сайте нажмите **«Войти через Telegram»**.
2. Откроется бот → нажмите **Start** (или отправьте `/start <код>`).
3. Сайт войдёт автоматически под вашим Telegram-аккаунтом.

### Управление задачами из бота
1. В боте: **📋 Мои задачи** (или `/tasks`).
2. У каждой задачи кнопки: **✅ Готово**, **🔄 Статус**, **💬 Коммент**, **📎 Док-во**.
3. Для задачи с обязательным доказательством: ✅ Готово → бот попросит 📎 → отправьте текст/ссылку → теперь ✅ закроет задачу.
4. Изменения сразу видны на сайте (real-time).

### Проект = Telegram-группа
1. На сайте откройте проект → кнопка **«Группа»** → **Получить код привязки**.
2. Добавьте **@clatask_bot** в группу, отправьте там `/link <код>`.
3. Создайте/измените задачу проекта на сайте → событие придёт в группу.

### Напоминания
Задачи со сроком в пределах 1 часа/1 дня → напоминание прилетит в личку бота
(планировщик проверяет раз в минуту).

## Примечания
- После тестов **отзовите токен** через @BotFather (`/revoke`) — он засветился в переписке.
- `.env` в git не попадают (в `.gitignore`).
