# Gram — мессенджер (аналог Telegram)

Полнофункциональный мессенджер: сервер, веб-клиент и нативное приложение для macOS.

## Возможности

- 💬 Личные и групповые чаты
- ⚡ Доставка сообщений в реальном времени (WebSocket) с мгновенным подтверждением
- ✓ / ✓✓ Статусы доставки и прочтения
- ⌨️ Индикатор «печатает…»
- 🟢 Статус «в сети» и «был(а) N минут назад»
- 🔍 Поиск пользователей по имени и логину
- ✏️ Редактирование и удаление своих сообщений
- 📜 История с подгрузкой старых сообщений при прокрутке
- 🔔 Нативные уведомления (в браузере и на macOS) и бейдж непрочитанных в доке
- 🌙 Светлая и тёмная темы
- 🔐 Регистрация и вход: пароли — scrypt, сессии — подписанные HMAC-токены

## Структура

```
messenger/
├── server/    Сервер: Node.js (REST API + WebSocket), SQLite (node:sqlite)
├── web/       Веб-клиент: HTML/CSS/JS без сборки, отдаётся сервером
└── desktop/   Приложение для macOS: Electron + electron-builder
```

Единственная зависимость сервера — пакет `ws`. База данных — встроенный
SQLite из Node.js 22.5+, без нативной компиляции.

## Запуск сервера и веб-клиента

Требуется Node.js ≥ 22.5.

```bash
cd messenger/server
npm install
npm start
```

Откройте http://localhost:3000 — это веб-клиент. Зарегистрируйте двух
пользователей в разных браузерах (или обычное + приватное окно) и напишите
друг другу.

Переменные окружения:

| Переменная      | По умолчанию       | Назначение                          |
|-----------------|--------------------|-------------------------------------|
| `PORT`          | `3000`             | Порт HTTP/WebSocket                 |
| `HOST`          | `0.0.0.0`          | Адрес для прослушивания             |
| `GRAM_DATA_DIR` | `server/data`      | Каталог базы данных и секрета       |
| `GRAM_SECRET`   | генерируется       | Ключ подписи токенов                |
| `GRAM_WEB_DIR`  | `../web`           | Каталог статики веб-клиента         |

## Приложение для macOS

Сборка выполняется на Mac (electron-builder собирает .dmg только на macOS):

```bash
cd messenger/desktop
npm install
npm start        # запуск в режиме разработки
npm run dist     # сборка Gram.dmg (arm64 + x64) в desktop/dist/
```

По умолчанию приложение подключается к `http://localhost:3000`.
Адрес сервера меняется через меню **Gram → Адрес сервера…** (⌘,) —
укажите адрес машины, где запущен сервер, например `http://192.168.1.10:3000`.

Особенности macOS-версии:

- скрытый заголовок окна в стиле нативных приложений (hiddenInset);
- бейдж с числом непрочитанных на иконке в доке;
- нативные уведомления;
- русифицированное меню, поддержка тёмной темы системы.

## Архитектура

- **REST API** (`/api/*`) — аккаунты, чаты, история сообщений. Авторизация —
  заголовок `Authorization: Bearer <token>`.
- **WebSocket** (`/ws?token=…`) — события в реальном времени: новые
  сообщения, подтверждения (`ack` по `tempId`), «печатает», статусы
  «в сети», отметки о прочтении, правки и удаления.
- Клиент шлёт сообщения через WebSocket с оптимистичным отображением;
  при разрыве соединения автоматически переключается на REST и
  переподключается с экспоненциальной задержкой.
- Личные чаты дедуплицируются: повторное создание чата с тем же
  собеседником возвращает существующий.

### Схема БД

`users` → `chats` (`direct`/`group`) → `chat_members` (с `last_read` для
подсчёта непрочитанных и галочек ✓✓) → `messages` (мягкое удаление).
